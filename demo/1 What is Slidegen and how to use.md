# Slidegen
## Turn Your Learning Materials into Presentations

Slidegen is a lightweight, JavaScript-based presentation platform designed primarily for teachers, academicians, and learners. Transform Markdown, Jupyter Notebooks (`.ipynb`), and CSV files into browser-based presentations. Share lecture slides, notes, datasets, and supplementary resources through simple web links, without maintaining a dedicated backend server.

**Create. Present. Share.**
---
## Key Benefits

### 1. Present Multiple File Formats
Convert Markdown documents, Jupyter Notebooks, and CSV files into structured, browser-based presentations.

### 2. GitHub-Powered Content Hosting
Use GitHub repositories as static file storage. Host and distribute presentation content without requiring a dedicated backend server or database.

### 3. Print-Ready Presentations
Print slides for classroom distribution, offline reference, or creating physical teaching materials.

### 4. Presenter Notes
Access presentation notes to support lecture delivery and keep additional explanations separate from the main slides.

### 5. Offline Presentation Access
Open and present downloaded presentation materials without requiring a continuous internet connection.

### 6. Share Learning Resources
Distribute notebooks, datasets, lecture notes, and other supplementary files alongside presentations, making it easier for students to access learning materials.
---
## How to Use Slidegen

### Step 1: Prepare Your Content
Create your presentation materials using Markdown (`.md`), Jupyter Notebook (`.ipynb`), or CSV files. Organize supplementary documents, images, and datasets in your GitHub repository.

### Step 2: Host Your Files on GitHub
Upload your presentation files and supporting resources to a GitHub repository. The repository acts as static file storage for your content.

### Step 3: Open Your Presentation
Use Slidegen to access your hosted content and transform supported files into browser-based slides.

### Step 4: Present and Share
Open the presentation in your browser and share its link with students or colleagues. Use presenter notes when delivering lectures.

### Step 5: Print or Access Offline
Print slides for physical distribution or download the required materials for offline presentation and reference.
